# 🎓 КлассМейт — Умный помощник школьника (5–11 классы)

Современное кроссплатформенное приложение на **Flutter**, созданное для школьников. Помогает мгновенно найти любую формулу, теорему, определение, правило или подсказку к контрольной и экзамену.

---

## ✨ Ключевые возможности

1. **🚀 Анимированный экран первого входа (Онбординг)**:
   - Стильная иконка с гладким сквирклом и шапочкой выпускника.
   - Чистое поле для ввода имени (пустое по умолчанию).
   - Выбор класса (по умолчанию 8 класс).
   - **Темная тема («Ночной космос») по умолчанию** с возможностью выбора любой из 4 тем.

2. **👋 Персонализированное главное меню**:
   - Приветственный баннер: **«Здравствуй, [Имя]! 👋»** (или просто «Здравствуй! 👋», если имя не указано).
   - Мгновенное переключение класса в один клик прямо в ленте категорий или через настройки.

3. **🔍 Сквозной мгновенный поиск**:
   - Ищет на лету по всем темам, формулам, понятиям, терминам и тегам (например: `дискриминант`, `закон ома`, `пифагор`, `площадь`, `односоставные`).

4. **📚 Полная база знаний для 8 класса (и других параллелей)**:
   - **Алгебра 8**: Рациональные дроби, Квадратные корни, Квадратные уравнения (D и теорема Виета), Дробно-рациональные уравнения, Числовые неравенства, Степени.
   - **Геометрия 8**: Параллелограмм, Прямоугольник/Ромб/Квадрат, Трапеция, Все формулы площадей, Теорема Пифагора, Подобие треугольников, Тригонометрия, Окружность и касательные.
   - **Физика 8**: Тепловые явления, Количество теплоты, Фазовые переходы, Тепловые двигатели, Электрический заряд, Закон Ома, Соединения проводников, Закон Джоуля-Ленца, Магнетизм, Оптика и линзы.
   - **Химия 8**: Вещества и явления, Валентность, Типы химических реакций, Моль и объемы газов, Периодический закон и атом, Основные классы неорганических веществ, Растворы.
   - **Русский язык 8**: Словосочетания, Главные члены предложения, Односоставные предложения, Причастные и деепричастные обороты, Вводные слова.
   - **Биология 8**: Кровь и круги кровообращения, Нервная система и рефлекторная дуга.
   - **География 8**: Границы, рельеф, климат и внутренние воды России.
   - **История 8**: Реформы Петра I, Дворцовые перевороты, Екатерина II.
   - **Информатика 8**: Системы счисления, Алгебра логики и таблицы истинности.

5. **🎨 4 темы оформления**:
   - 🌌 **«Ночной космос» (Midnight Cyber)** — установлена по умолчанию!
   - 🌟 **«Лазурный день» (Modern Blue)** — чистая современная светлая тема.
   - 🍵 **«Мятный чай» (Emerald Matcha)** — мягкая пастельная тема цвета шалфея.
   - 📜 **«Школьная тетрадь» (Warm Notebook)** — теплая крафтовая бумага и конспекты.

6. **💾 Надежное сохранение данных**:
   - Все настройки (имя, класс, выбранная тема, избранные шпаргалки) автоматически сохраняются в `%APPDATA%/ClassMateApp/user_settings.json` и в рабочей папке. При закрытии и перезапуске приложения всё мгновенно восстанавливается!

---

## 🚀 Как запустить

Дважды кликните по файлу **`run_app.bat`** в корне папки проекта:
- **1** — Запуск для Windows Desktop
- **2** — Запуск в браузере Chrome
- **3** — Запуск в браузере Edge
